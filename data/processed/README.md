# Processed Data Directory

This directory stores windowed and feature-extracted datasets generated by `scripts/prepare_data.py`:
- `train_features.csv`, `val_features.csv`, `test_features.csv`: Tabular time-domain and frequency-domain vibration features.
- `train_windows.npy`, `val_windows.npy`, `test_windows.npy`: Normalized raw vibration window arrays of shape `(N, 2048)` for 1D CNN training.
- `splits_summary.json`: Detailed manifest of the recording groups in each partition, guaranteeing zero group overlap and zero data leakage.
