🛡️ Zero Data-Leakage Protocol

RIGOROUS VALIDATION
  • ✔ GroupShuffleSplit by recording_id: No window from the same physical recording run appears in both training and test sets.
  • ✔ Unseen Load Generalization: Test set tests models against load conditions (0% and 10%) never seen during gradient updates.
  • ✔ No Fabricated Classes: Ground truth strictly tracks `Healthy` and `BrokenTooth` as established by DOE OpenEI physical ground truth.

🔌 FastAPI REST API Specification

BASE: http://localhost:8000
GET /health
System health check distinguishing app readiness from model artifact status
GET /models
Lists all available trained models (Random Forest, XGBoost, 1D CNN, Anomaly Detector)
POST /predict
Accepts 2048 vibration float samples, returns classification, anomaly score & state
GET /machines
Returns list of registered machine IDs and operational status
GET /alerts
Fetches deduplicated active, acknowledged, or resolved alert records
POST /alerts/{alert_id}/acknowledge
Marks active alert as acknowledged by maintenance engineer
POST /alerts/{alert_id}/resolve
Marks alert resolved following mechanical repair or physical inspection
